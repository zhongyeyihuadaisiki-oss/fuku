# 二手网站 保存搜索链接

最后更新：2026-09-28（按体型偏胖/偏紧身要避免 + 更多平台调整）

**用法**：手机浏览器（或电脑）登录后打开链接 → 点「この検索条件を保存」（ヤフオク是「検索条件を保存」）→ 在App里打开保存条件的新着推送。

筛选已经包含：男装分类、M+L码、新品/未使用に近い、只看在售、素色（黑/藏青/灰/米色/棕/卡其/白）、按上架时间排序、价格上限（外套≤8000〜10000、上衣≤5000〜6000、裤子≤6000）。

**关于版型（避免紧身）**：Mercari 的URL参数里没有「宽松/修身」这个筛选项，没法直接拼进链接。翻的时候自己跳过标题写「スキニー」「スリム」「タイト」的；优先找写「ワイド」「テーパード」「リラックス」「ゆったり」「オーバーサイズ」的。裤子部分我额外加了一条带「テーパード」关键词的搜索，方便直接看宽松锥形西裤款。
