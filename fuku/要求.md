# 买衣服的要求（给新对话的Claude先读这个）

最后更新：2026-09-28

## 我是谁

- 住东京南千住，男，**165cm / 63kg**，偏重一点
- 公司没有着装要求，平时穿**休闲日常**就行
- 东京冬天对我来说不冷，**不需要羽绒服**，普通秋冬外套、稍微厚一点就够

## 尺码

- **M 和 L 都可以**，不用硬选；想穿得稍微宽松一点
- 看实际尺寸（実寸）比看标码靠谱。参考：外套身幅 ≥ 55cm、上衣身幅 ≥ 56cm 会比较宽松；修身款（身幅50左右）会紧
- 裤子：腰围约 76〜84cm，最好是松紧腰或有弹力；内长68〜72cm左右，不用改裤脚

## 风格

- **不要太私人化、不要太花哨**：素色（黑、藏青、灰、米色、棕、卡其，上衣可以白），不要大logo、印花、亮色
- **也不要太正式**：不要西装外套、商务衬衫、带领带那种
- 目标是日本上班族周末或通勤穿的那种"不显眼、百搭"的感觉
- 优先顺序：**面料质感 ＞ 成色 ＞ 百搭 ＞ 价格**。不一定要牌子货，但品质要好

## 衣柜计划（按东京上班族的实际穿法）

- 5〜10月：短袖、长袖T、衬衫一件出门
- 11月前后・3〜4月：不穿薄外套，在T恤外面加开衫、衬衫夹克（シャツジャケット）或毛衣
- 12〜2月：一件像样的外套（中棉夹克、大衣之类，素色）
- 要买的：冬季外套1件、开衫/衬衫夹克/毛衣2〜3件、长袖T/衬衫5〜6件、裤子3条（冬天另加1条保暖裤）；**薄外套（ブルゾン、冲锋衣之类）先不买**

## 硬性条件

- 成色：**新品 或 未使用に近い**（几乎全新）
- **最好能直接机洗**（说明里写「ウォッシャブル」「洗濯機で洗える」「洗える」的优先）；纯羊毛、真丝这类只能手洗或干洗的不要
- 运费：只要包邮（メルカリ上写「送料込み」的）
- 买二手：外套、毛衣、卫衣、衬衫、裤子都可以
- **不买二手**：内衣内裤、袜子、鞋子

## 找衣服的方式（已决定）

- 想买的时候直接对Claude说：**「读 Documents\fuku\要求.md，帮我找○○」**（比如"秋天的外套2件""裤子3条"）
- Claude 去メルカリ（主要）/ヤフオク/楽天搜，逐件核对后列出来；不再做推荐页或爬虫
- 平时想随便看看：打开メルカリ的「保存した検索条件」

## 推荐商品时的做法

1. 每件都要列：**二手价 / 新品原价 / 便宜了多少%**。原价以卖家写的定価或官网价为准，查不到就写"未确认"
2. 点进商品页确认：**分类是メンズ**（标题写M但其实是女款的情况很常见）、尺码、实际尺寸、成色、能不能洗
3. 看照片：前几张经常是官网模特图，要找有没有实物照；注意领口发黄、起球、面料本身的皱感（不是折痕）
4. 折扣只有两三成的二手不值得，不如等官网打折买新的
5. 优衣库的二手省不了多少钱（一件省一两千日元），好一点的牌子买二手最划算

### 为什么二手网站不用脚本

メルカリ利用规约禁止「用官方界面以外的方式访问服务」，ヤフオク的搜索API也早就停了。硬抓有封号风险，所以用App自带的保存搜索推送。
